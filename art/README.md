# 원본 그림 (art/)

ChatGPT로 만든 원본 그림을 보관합니다. 앱에 그대로 실리지 않고, 웹용으로 변환한 파일이 `public/images/` 로 들어갑니다.

| 폴더 | 내용 |
|---|---|
| `characters/` | 캐릭터 시트 7장 — 장면을 만들 때 ChatGPT에 첨부하는 기준 그림 |
| `icon/` | 앱 아이콘 원본 그림 |
| `stories/` | 동화 장면 원본(투명 배경). 앱에는 밤하늘 등 배경색을 입혀 WebP로 변환해 넣음 |

캐릭터 시트는 받은 그대로가 아니라, 배경 제거 후 남은 반투명 얼룩(노란·빨간 번짐, 점)을 지운 버전입니다.
이 과정에서 별의 은은한 빛 번짐과 작은 효과선(놀람 표시, 떨림 선)도 함께 빠졌습니다. 빛 효과는 앱에서 따로 입힙니다.

## 확정된 캐릭터 특징
- 미니: 갈색 단발 + 옆머리 작은 올림머리, 주황 머리핀, 흰 둥근 깃 산호색 원피스 / 노란 저고리·빨간 고름·분홍 치마
- 나비: 주황 줄무늬 고양이 (시트의 빨간 스카프는 『작은 별』 장면에 없어 확인 필요)
- 작은 별: 노란 별, 점 눈, 볼터치
- 부엉이: 갈색, **동그란 안경**
- 강아지: 베이지색, 갈색 귀와 등 얼룩
- 개구리: 연두색, 등에 진한 점 / 참새: 갈색 날개, 크림색 배
- 할머니: 은발 쪽머리, 연보라 한복(소매에 꽃무늬), 짙은 보라 고름

# 엄마말 그림책

이주배경 아이들이 **모국어와 한국어로 함께 읽고**, 한국어 낱말을 듣고·고르고·따라 쓰고·받아쓰며 익히는 휴대폰용 그림책 웹앱입니다. 홈 화면에 설치하는 PWA라서 한 번 열면 오프라인에서도 읽을 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 두 언어 읽기 | 그림 아래 모국어·한국어 문장. 보기 방식 `함께 / 모국어만 / 한국어만` |
| 소리 내어 읽기 | 모국어 → 한국어 순서로 읽어 줌. 기기에 해당 언어 음성이 없으면 안내 후 한국어만 |
| 낱말 익히기 | 문장 속 낱말을 누르면 한국어·모국어 발음, 쪽마다 낱말 카드 |
| 낱말 놀이 | 듣고 그림 고르기 / 그림·뜻 보고 한국어 낱말 고르기 |
| 따라 쓰기(획순) | 한글 표준 획순으로 획마다 시작점·방향 안내, 손가락으로 따라 쓰면 시작점·방향·모양을 판정 |
| 받아쓰기 | 글자 블록(유아용) 또는 자판 입력, 천천히 듣기·힌트 |
| 문화 이야기 | 『설날 아침』 + 아이 언어권의 새해 문화 비교 카드, 부모와 대화 질문 |
| 내 낱말장 | 맞힌 낱말 모으기, 받아쓰기 완료 ✎ 표시 |

지원 언어: 러시아어 · 몽골어 · 베트남어 · 우즈베크어 · 중국어 · 영어 (+ 한국어)
권장 연령: 만 4~8세 (문해력 지원이 필요한 초·중학생은 확장 대상)

## 개발

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 + 서비스워커 생성
npm run preview    # 빌드 결과 확인
```

하위 경로에 배포할 때는 `BASE_PATH=/eommamal/ npm run build` 처럼 경로를 지정합니다.

## 구조

```
src/
  content/
    data.js        동화·낱말·문화 카드 텍스트 (모든 언어)
    art.js         동화 그림(SVG) 그리는 함수
    index.ts       파생 데이터 (낱말 목록, 문장 속 낱말 찾기 등)
  lib/
    hangul.js      한글 자모 획순 데이터 + 따라 쓰기 판정
    speech.ts      소리 내어 읽기 (브라우저 음성 → 추후 녹음 파일로 교체)
    progress.tsx   학습 기록 (현재 기기 저장 → 추후 서버로 교체)
  screens/         홈 · 읽기 · 다 읽음 · 낱말 놀이 · 따라 쓰기 · 받아쓰기 · 결과
```

### 동화 추가하기

1. `src/content/data.js` 의 `STORIES` 에 동화(제목·쪽별 문장 7개 언어·그림 함수)를 추가합니다.
2. 새 낱말은 `V`(뜻)와 `ICON`(그림)에 추가하고, `PW` 에 쪽별 낱말을 적습니다.
3. 획순이 없는 자모(예: 겹받침, ㅘ 같은 복합 모음)가 들어간 낱말은 따라 쓰기에서 자동으로 빠집니다. `src/lib/hangul.js` 의 `J` 에 획을 추가하면 지원됩니다.

## 검수 필요

- 모든 번역과 문화 카드 내용은 초안입니다. **원어민 검수 후 서비스**해야 합니다.
- 획순과 따라 쓰기 판정 기준은 한글 교육 전문가 검수와 실제 아이들 사용 테스트로 조정이 필요합니다.

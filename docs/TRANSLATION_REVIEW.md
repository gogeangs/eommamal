# 번역 검수

주소: `https://gogeangs.github.io/eommamal/#review` (관리 화면 → "번역 검수"에서도 들어가요)

## 화면
- 언어를 고르면 그 언어의 모든 글이 나와요: 동화(제목·책장 소개·쪽), 낱말, 문화 카드, 아이 화면 문구, 보호자 화면 문구.
- 줄마다 **한국어 원문**과 **영어 참고**가 위에 있고, 그 아래 칸에서 바로 고쳐요.
- 고친 글은 이 기기에서 곧바로 앱에 보여요(미리 보기). "앱에서 보기"로 확인해요.
- ✓ 확인: 맞는 글 / ⚑ 다시 보기: 애매하거나 원문을 다시 봐야 하는 글(메모 가능) / 원래 글로: 고친 것 취소
- `{name}`, `{n}` 같은 표시는 지우면 안 돼요. 지우면 빨간 경고가 나와요.
- 위쪽에 검수 진행률(검수한 줄 / 전체 줄)이 보여요. "검수 전" 필터로 남은 줄만 볼 수 있어요.

## 저장 방법
1. **서버 (권장)**: 검수자 계정으로 로그인 → "서버에 저장". 모든 기기에 반영돼요. (서버 설정과 검수자 지정 필요: docs/SUPABASE.md)
2. **파일**: 서버가 없거나 권한이 없으면 "검수 파일 내려받기" → 운영자에게 보내요.
   운영자는 같은 화면에서 "검수 파일 불러오기" → "관리 화면 작업 내용에 넣기" → 관리 화면 "내려받기·게시"로 게시해요.

## 저장되는 곳
- 고친 글은 콘텐츠 팩의 `text` (언어 → 키 → 글), 검수 표시는 `review` 에 저장돼요. 앱 코드의 원래 번역은 그대로 두고 앱이 켜질 때 덮어써요.
- 키 목록과 적용 방식: `src/content/i18n.ts`

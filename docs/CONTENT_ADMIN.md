# 콘텐츠 관리 화면 사용법

주소: `https://gogeangs.github.io/eommamal/#admin` (앱 아래 "보호자 안내 · 문의" → "콘텐츠 관리 (운영자용)")

코드를 고치지 않고 동화·번역·낱말·그림·문장 받아쓰기를 고치거나 새로 만들 수 있어요.
작업 내용은 **그 브라우저에 자동 저장**되고, 다 되면 파일로 내려받아 게시해요.

## 할 수 있는 일
| 메뉴 | 내용 |
|---|---|
| 동화 | 기존 동화 번역 고치기(원어민 검수 반영), 새 동화 만들기, 쪽 추가·삭제·순서 바꾸기, 쪽 그림 올리기, 쪽마다 낱말 고르기, 문장 받아쓰기 문장, 전래 동화 표시, 책장에서 숨기기 |
| 낱말 | 기존 낱말 번역·그림·타일 색 고치기, 새 낱말 추가 |
| 내려받기·게시 | content.zip 내려받기, 이전 파일 불러와 이어서 작업, 작업 내용 지우기 |

- 번역 칸이 비어 있으면 "빈칸 N"으로 표시돼요. 비어 있는 언어는 앱에서 한국어로 보여요.
- 그림은 올리면 자동으로 웹용(WebP)으로 바뀌어요. 쪽 그림은 1200×800(3:2), 투명한 부분은 고른 배경색으로 채워요. 낱말 그림은 384×384 투명 배경으로 잘라요.
- ChatGPT 그림의 배경 얼룩 정리는 아직 관리 화면에서 못 해요. 얼룩이 심하면 Claude에게 보내 주세요.

## 게시 순서
1. **이 기기에서 미리 보기** — 이 휴대폰·컴퓨터에서만 바뀐 내용으로 앱이 열려요. 위쪽 검은 막대의 "끝내기"로 돌아와요.
2. **내려받기·게시 → 콘텐츠 파일 내려받기** — `content.zip`
3. 압축을 풀면 나오는 `content` 폴더를 GitHub 저장소 `public` 폴더에 올려요 (GitHub 웹에서 public 폴더 → Add file → Upload files → 폴더째 끌어 놓기 → Commit).
   → 몇 분 뒤 자동 배포되어 모든 사람에게 보여요. 파일을 Claude에게 보내도 돼요.

## 구조 (개발자용)
- `src/content/pack.ts` — 콘텐츠 팩 형식(`Pack`)과 기본 콘텐츠(data.js)에 덮어쓰는 `applyPack()`
- `src/lib/contentStore.ts` — 팩을 어디서 읽고 쓰는지(`ContentStore`). 지금은 `fileStore`
  (`public/content/pack.json` + 브라우저 저장). **Supabase로 바꿀 때는 이 인터페이스만 구현**하면 관리 화면은 그대로 써요.
- `src/screens/Admin.tsx` — 관리 화면, `src/lib/imageTools.ts` — 그림 변환
- 앱은 시작할 때 게시된 팩 → (있으면) 미리 보기 팩 순서로 적용한 뒤 화면을 그려요.
- 이 화면에는 로그인이 없어요. 누구나 열 수 있지만 고친 내용은 그 사람 브라우저에만 남고, 게시는 GitHub 권한이 있어야 해요.

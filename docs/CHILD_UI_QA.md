# 어린이 친화 UI QA (2026-11-09)

이 브랜치의 목표는 4~8세 아동이 읽기 능력과 상관없이 그림과 소리로 조작할 수 있도록 만드는 것입니다.

## 자동 점검
- [ ] `npm ci && npm run build`
- [ ] React/TypeScript 콘솔 오류 없음
- [ ] PWA 오프라인에서 기존 3편과 학습 기록 접근

## 실제 기기 점검
- [ ] 320/360/390/430px 화면에서 카드/버튼/모달 가로 넘침 없음
- [ ] 4~6세 아동이 보호자 도움 없이 이야기와 낱말 놀이 시작
- [ ] 3개 그림 중 틀린 답을 눌렀을 때 안내가 친절하고 재시도 가능
- [ ] 정답을 맞힌 뒤 스스로 '다음'을 누를 수 있음
- [ ] 받아쓰기 첫 화면엔 힌트가 없고, 오답 후 천천히 듣기와 그림 힌트가 단계적으로 나타남
- [ ] 따라쓰기 노란 시작점/화살표를 잘 보고 따라갈 수 있음
- [ ] 종료 후 별점 압박 없이 모은 낱말과 다음 행동 확인
- [ ] 다른 책을 읽고 나와도 마지막 책이 이어 읽기 최상단에 보임
- [ ] 잠긴 낱말 때문에 학습 화면이 가득 차지 않음
- [ ] 언어/읽기/자판 설정 변경 뒤 다시 진입해도 기록이 유지됨
- [ ] 스크린 리더에서 선택 버튼과 소리 버튼의 목적이 구분됨

## 번역 및 교육 감수
- [ ] 러시아어/몽골어/베트남어/우즈베크어/중국어/영어 버튼 번역 원어민 감수
- [ ] 브라우저 TTS 사용 불가능한 기기에서 보호자 안내가 정상 표시
- [ ] 학습 과제 난이도와 오답 처리 방식 4~6세 / 7~8세 그룹별 관찰

## 추후 완성 과제
- 원어민 음성 녹음 파일 확보 및 언어별 과제 안내 전체 음성화
- 4~6세 / 7~8세 연령 모드 세분화
- 낱말 수집을 별자리·정원 등 일러스트 수집판으로 시각화
- 보호자 진입 잠금 방식과 문화/문장 번역 원어민 검수

## 1. MVP (약 6~8주)
- **콘텐츠 관리자 화면**: 동화·번역·낱말·그림·녹음을 코드 수정 없이 등록 (Supabase DB + Storage)
- **원어민 녹음 음성**: `lib/speech.ts` 를 녹음 파일 재생으로 교체, 기기 음성은 예비용
  - 몽골어·우즈베크어는 기기 음성이 없는 경우가 많아 필수
- **동화 5~10편 확보**: 원어민 번역 검수 + 감수 절차
- 받아쓰기 2단계: 낱말 → 동화 속 짧은 문장
- 읽기 단계 구분(1단계 그림+낱말 / 2단계 짧은 이야기 / 3단계 나이에 맞는 소재+쉬운 문장)

## 2. 기관용 (시범 운영)
- 기관(도서관·이주민 단체·지역아동센터)이 반을 만들고, 아이는 **닉네임 + 그림 암호**로 입장
  - 만 14세 미만 실명·연락처 수집 없이 시작 → 법정대리인 동의 부담 최소화
- 선생님·사서용 진도 화면: 읽은 책, 낱말 놀이·받아쓰기 결과, 자주 틀리는 낱말
- 안산 원곡동·선부동 시범 운영

## 3. 확장
- 언어 추가 (캄보디아어, 네팔어, 태국어 등 지역 수요 기준)
- **우리 나라 이야기**: 각 나라 부모가 들려주는 명절·옛이야기 → 한국 아이들도 함께 읽는 양방향 콘텐츠
- 문화 이야기 시리즈: 추석, 한글날, 김장 ↔ 각 나라의 대응 문화
- 부모 녹음 기능: 엄마 아빠 목소리로 동화 읽어 주기

## 기술 메모
- 화면은 `content/`(데이터)와 `lib/progress.tsx`(기록), `lib/speech.ts`(소리)에만 의존 → 이 세 모듈만 서버 연동으로 바꾸면 됨
- 그림은 현재 코드로 그린 SVG. 실제 서비스에서는 일러스트 파일(WebP/SVG)로 교체 권장
